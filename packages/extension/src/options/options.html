review-ratio

A private badge in the GitHub header: how much you review compared to how much you ask to be reviewed. Nobody else sees your ratio.

GitHub token

Create a fine-grained personal access token with resource owner DiliTrust, access to all repositories, and these read-only permissions: Pull requests, Contents, Metadata. The token stays in this browser and is only sent to api.github.com.

Scope

Server

The server receives numbers only: no login, no repository, no PR number, no file name. Open DevTools on the service worker to see the exact payload.
