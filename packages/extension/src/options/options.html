review-ratio

A private badge in the GitHub header: how much you review compared to how much you ask to be reviewed. Nobody else sees your ratio. The extension computes it in this browser: nothing leaves it except calls to GitHub (api.github.com, and github.com to sign in).

Create a fine-grained personal access token with resource owner your organisation, access to all repositories, and these read-only permissions: Pull requests, Contents, Metadata. The token stays in this browser and is only sent to api.github.com.

Scope

The organisation whose pull requests count, as in github.com/your-company. Each organisation decides what outside tools may read: some must install the app first, some require single sign-on, some refuse tokens. Save checks that yours lets review-ratio in, and says what to do when it does not.
